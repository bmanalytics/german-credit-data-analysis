

# German Credit Data Analysis

# Exploratory Data Analysis with Python and Power BI


**1. Project Overview**

This project presents an Exploratory Data Analysis (EDA) of the German Credit dataset, originally provided by the UCI Machine Learning Repository.

The objective is to investigate customer characteristics and identify patterns and associations related to credit risk.

**2. Dataset**

1,000 observations

20 explanatory variables

1 target variable

No missing values

**3. Tools and Technologies**

Python

Pandas and NumPy

Matplotlib and Seaborn

Statistical Analysis

Power BI

**4. Methodology**

Data cleaning and preparation

Descriptive statistics

Univariate and bivariate analysis

Correlation analysis

Cramér's V association analysis

Data visualization using Power BI

**5. Main Findings**

The exploratory analysis identified relevant associations between credit classification and variables such as checking account status, credit history, savings account status and credit purpose.

**6. Project Files**

German_Credit_Portugues.ipynb – Python notebook containing the analysis.
Projeto1_German_Credit.pdf – Complete project report, including Power BI visualizations.

**7. Next Steps**

The next stage will focus on predictive modeling using Logistic Regression for credit risk classification.
